# CodingAgents 01 — Repo Understanding

A deep-dive into how coding agents read and navigate large codebases: ripgrep heuristics that outperform semantic search on cold queries, tree-sitter AST parsing for language-aware symbol extraction, ctags and Language Server Protocol symbol indexing, code-embedding models (CodeBERT, UniXcoder, voyage-code-3) and when dense retrieval actually helps, dependency and call-graph construction, caching strategies for multi-million-line repos, and the concrete approaches taken by Aider repo-map, Cursor @-references, and Claude Code's file-read heuristics.
